# Desktop-Pet 🐕

A cute Yorkshire Terrier that lives on your Windows desktop — always on top, always wagging, and always ready for attention.

---

## Features

### Interactive Desktop Companion

* Animated Yorkshire Terrier with:

  * Silky coat
  *  Gilli Nose
  * Floppy ears
  * Constant tail wagging
* Drag and place anywhere on your desktop
* Always stays on top of other windows

### Dynamic Mood System

Your Yorkie reacts to how much attention it gets:

| Mood      | Trigger                        |
| --------- | ------------------------------ |
| Idle   | Normal state                   |
| Happy  | After clicks or interaction    |
| Sleepy | After 30 seconds of inactivity |
| Hungry | When hunger becomes low        |

Additional animations include:
* Natural blinking
* Tongue-out happy expression
* Woof speech bubbles
* Random barking


### Hunger System
* Hunger decreases over time
* Visual hunger bar
* Feed your Yorkie anytime via the right-click menu


### Activity Counter
Tracks:
* Mouse clicks
* Keyboard presses
* Overall interaction activity


### 3D Roam Mode
Switch to Roam Mode and watch your Yorkie:
* Transform into a 3D  figure
* Walk back and forth along the taskbar
* Animate legs while moving
* Continue wagging its tail

Note: the activity counter would not be visible


Toggle anytime from the right-click menu.

## Running the Application

### Option 1: Launch Script

Double-click:
```bat
main.bat
```

### Option 2: Command Line
Open a terminal in the project folder and run:

```bash
python_main.py
```

---

## Controls

| Action             | Result                             |
| ------------------ | ---------------------------------- |
| Left-click Yorkie  | Bark and increase activity counter |
| Press any key      | Increase activity counter          |
| Right-click Yorkie | Open context menu                  |
| Drag Yorkie        | Move anywhere on screen            |

---

## 🖱 Right-Click Menu
Available options:
* Feed Yorkie
* Toggle Roam Mode
* Reset Counter
* Close Application

---

## Tips

* Yorkie always remains on top of other windows.
* Drag it to any location on your desktop.
* Roam Mode automatically moves the pet along the taskbar.
* Use the context menu to quickly switch modes or feed your pet.
* Reset the activity counter whenever you want a fresh start.
